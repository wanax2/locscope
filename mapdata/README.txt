Map boundary data bundled with LocScope (used offline):
- us-counties-10m.json   from us-atlas 3 (ISC license, Mike Bostock), derived from U.S. Census Bureau cartographic boundary files (public domain)
- world-countries-50m.json from world-atlas 2 (ISC license, Mike Bostock), derived from Natural Earth (public domain)
- topojson-client.min.js  topojson-client 3 (ISC license, Mike Bostock)
- airports.csv  large & medium airports with IATA codes, from OurAirports (public domain), via the airports-json npm package
